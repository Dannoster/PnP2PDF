# PnP2PDF

[![tests](https://github.com/Dannoster/PnP2PDF/actions/workflows/tests.yml/badge.svg)](https://github.com/Dannoster/PnP2PDF/actions/workflows/tests.yml)

[English](README.md) · **Русский** · [简体中文](README.zh-CN.md) · [Español](README.es.md) · [Deutsch](README.de.md)

PnP2PDF собирает карты для print-and-play в готовый к печати PDF. Выберите папку
с картинками карт, укажите бумагу и сетку — и получите один PDF с линиями реза,
безопасными зонами и, если нужно, рубашками, отзеркаленными на обратной стороне.

- одно окно, командная строка не нужна;
- живой предпросмотр листов до печати;
- карты без рубашек, одна общая рубашка, несколько разных рубашек и карты, где
  рубашка своя у каждой;
- настройки по умолчанию под A4 и карту 62,5 × 88,7 мм (покерный размер).

## Готовая сборка

Скачайте архив для своей системы в [Releases](https://github.com/Dannoster/PnP2PDF/releases),
распакуйте и запустите. Python устанавливать не нужно.

### Первый запуск на macOS

Сборки не подписаны сертификатом Apple, поэтому macOS спрашивает разрешение при
первом запуске. По порядку:

1. Двойной клик по приложению. Если macOS не даёт открыть, открой папку в Finder,
   **правый клик (Control-клик) по приложению → Открыть → Открыть**. Дальше система
   запоминает выбор.
2. Если в окне нет кнопки *Открыть*, открой **Системные настройки → Конфиденциальность
   и безопасность**, прокрути вниз до строки про PnP2PDF и нажми **Всё равно
   открыть**.
3. Если macOS пишет, что приложение *повреждено и не может быть открыто*, сними
   карантин один раз и запусти снова:

   ```bash
   xattr -dr com.apple.quarantine /Applications/PnP2PDF.app
   open /Applications/PnP2PDF.app
   ```

### Первый запуск на Windows

Неподписанный файл иногда ловит Defender SmartScreen: нажми **Подробнее →
Выполнить в любом случае**. С самим файлом всё в порядке, после первого запуска
предупреждение не появляется.

## Запуск из исходников

Нужен Python 3.11 или новее.

```bash
git clone https://github.com/Dannoster/PnP2PDF.git
cd PnP2PDF
pip install -r requirements.txt
python PnP2PDF.py
```

Установка пакета добавляет две команды: `pnp2pdf` открывает окно, `pnp2pdf-cli`
собирает PDF без окна.

```bash
pip install .
pnp2pdf
```

## Быстрый старт

1. **Cards folder** — выберите папку с картинками карт. Предпросмотр справа
   появится сразу после выбора папки.
2. **Бумага и размер карты** — по умолчанию A4 (210 × 297 мм) и карта
   62,5 × 88,7 мм. Галочка *Smaller size (98%)* печатает карты чуть меньше, тогда
   между ними остаётся больше бумаги.
3. **Раскладка** — строки × столбцы, зазор между картами и, при необходимости,
   безопасные зоны (поля, до которых принтер не достаёт).
4. **Double sided cards** — отметьте, если папка подготовлена с рубашками.
   Подробности в разделе [Раскладка папок](#раскладка-папок-с-картами): без этой
   галочки картинки рубашек печатаются как обычные карты.
5. **Create PDF** — шкала доходит до конца, окно остаётся открытым, статус
   становится зелёным с именем файла, а кнопка **Show PDF** открывает файл в
   Finder, Explorer или файловом менеджере.

PDF сохраняется в папку с отметкой времени рядом с картами. Галочка *Save the PDF
to a different folder* позволяет выбрать другое место.

## Раскладка папок с картами

*Папка с картами* — та, которую вы выбираете в окне. Всё описанное ниже лежит
внутри неё. Поддерживаются `.png`, `.jpg`, `.jpeg`, `.tif`, `.tiff`.

Картинки растягиваются на область карты, поэтому берите изображения с тем же
соотношением сторон, что и у карт.

### Карты без рубашек

Просто положите картинки в папку и ничего не отмечайте:

```
my-cards/
├── card-01.png
├── card-02.png
└── card-03.png
```

### Одна рубашка для всех карт

Рубашка — это картинка, имя которой заканчивается её размером в миллиметрах, а
карты лежат в подпапке с тем же именем, но **без размера**:

```
my-cards/
├── red-back_63,5_88,9.png     ← рубашка, размер в имени
└── red-back/                  ← карты, которые печатаются с этой рубашкой
    ├── card-01.png
    └── card-02.png
```

Отметьте **Double sided cards** и соберите PDF. За каждым листом с лицами идёт
тот же лист с рубашками, отзеркаленный так, чтобы карты совпали при двусторонней
печати.

### Несколько рубашек

Схема та же: один файл рубашки — одна папка. Карты с разными рубашками могут быть
разного размера, они раскладываются вместе.

```
my-cards/
├── red-back_63,5_88,9.png
├── blue-back_64,5_91,3.png
├── red-back/
│   └── card-01.png …
└── blue-back/
    └── card-01.png …
```

Размер в имени не обязателен: без него рубашка растягивается на размер карты.
С ним рубашка больше карты обрезается по окну карты, чтобы вылеты и метки
совмещения не попали на напечатанную карту. Разделитель дробной части — запятая
или точка: `63,5` и `63.5` равнозначны.

### Карты со своей рубашкой

Если задняя сторона относится только к одной карте, положите обе картинки в
папку `Double Sided`. Файлы разбиваются на пары по алфавиту: лицо, рубашка,
лицо, рубашка…

```
my-cards/
└── Double Sided/
    ├── 1-front.png
    ├── 2-back.png
    └── 3-front.png …
```

Нечётное число файлов не принимается: программа объяснит, что пары бы сдвинулись.

### Карты без рубашки в смешанном наборе

Для них есть папка `Single Sided`:

```
my-cards/
├── Double Sided/…
└── Single Sided/
    ├── card-01.png
    └── card-02.png
```

Все четыре схемы можно смешать в одной папке и собрать за один запуск.

> **Не забудьте про галочку.** Структура папок говорит, *какая рубашка к какой
> карте относится*, а галочка **Double sided cards** — печатать ли эти рубашки.
> Если она снята, картинки рубашек считаются обычными лицами и попадают на лист
> рядом с картами.

## Настройки

| Настройка | По умолчанию | Замечание |
| --- | --- | --- |
| Размер бумаги | 210 × 297 мм | A4. Любой размер в миллиметрах. |
| Размер карты | 62,5 × 88,7 мм | Покерный размер. Картинки растягиваются на этот прямоугольник. |
| Smaller size (98%) | выключено | Печатает каждую карту на 98% указанного размера. |
| Строки × столбцы | 3 × 3 | Карт на листе. |
| Зазор | 2 мм | Расстояние между картами, по нему идут линии реза. |
| Безопасная зона сверху/снизу | 0 мм | Поля, до которых принтер не достаёт. |
| Безопасная зона слева/справа | 0 мм | То же по горизонтали. |
| Папка с картами | — | Папка, описанная выше. |
| Куда сохранить PDF | рядом с картами | Необязательно, можно выбрать другую папку. |
| Double sided cards | выключено | Печатать рубашки карт. |

Настройки запоминаются между запусками в `presets.json` в папке данных
приложения (пути — в разделе [Если что-то пошло не так](#если-что-то-пошло-не-так)).
При запуске из исходников файл лежит рядом с проектом.

## Примеры

В [`examples/`](examples/) лежат готовые наборы карт для каждой схемы — по
несколько килобайт каждый — и `make_examples.py`, который их пересоздаёт.
Подробности — в [`examples/README.md`](examples/README.md).

| Папка | Что показывает | Страниц |
| --- | --- | --- |
| `single-sided/` | девять карт без рубашек | 1 |
| `one-back/` | шесть карт с одной общей рубашкой | 2 |
| `two-backs/` | две рубашки, одна больше карт | 4 |
| `double-sided/` | парные карты плюс односторонние в одном запуске | 2 |

```bash
python3 -m pnp2pdf.cli --cards examples/one-back --out /tmp/ex --double-sided --quiet
```

## Командная строка

`pnp2pdf-cli` собирает те же PDF без окна — удобно для скриптов и пакетной
обработки.

```bash
pnp2pdf-cli --cards ~/cards --out ~/pdf
pnp2pdf-cli --cards ~/cards --out ~/pdf --double-sided
pnp2pdf-cli --cards ~/cards --preview /tmp/first-page.png
```

| Ключ | Значение |
| --- | --- |
| `--cards DIR` | Папка с картинками карт (обязательно). |
| `--out DIR` | Куда писать PDF. По умолчанию — рядом с картами. |
| `--paper WxH` | Размер бумаги в мм, по умолчанию `210x297`. |
| `--card WxH` | Размер карты в мм, по умолчанию `62.5x88.7`. |
| `--grid RxC` | Строки × столбцы, по умолчанию `3x3`. |
| `--gap MM` | Зазор между картами в мм, по умолчанию `2`. |
| `--safe-ud MM` | Безопасная зона сверху/снизу в мм, по умолчанию `0`. |
| `--safe-lr MM` | Безопасная зона слева/справа в мм, по умолчанию `0`. |
| `--smaller-size` | Печатать карты на 98% указанного размера. |
| `--double-sided` | Печатать рубашки. |
| `--preview PATH` | Записать первую страницу в PNG и выйти. |
| `--quiet` | Без вывода прогресса. |
| `--version` | Показать версию и выйти. |

Коды выхода: `0` успех, `1` неожиданная ошибка, `2` неверные входные данные,
`130` отменено.

## Сборка отдельного приложения

Одна команда собирает приложение и сама лечит своё окружение:

```bash
./build_app.sh          # macOS и Linux
build_app.bat           # Windows
```

Скрипт создаёт `.venv`, если его нет, ставит или обновляет зависимости, заменяет
битое или чужое виртуальное окружение, прогоняет тесты и упаковывает приложение.
Результат:

- macOS: `dist/PnP2PDF.app`
- Windows: `dist/PnP2PDF.exe`
- Linux: `dist/PnP2PDF`

`--no-tests` пропускает тесты, `PNP2PDF_BUILD_DRY=1` проверяет окружение и
останавливается перед упаковкой. На macOS после записи версии сборка заново
подписывает приложение и падает с понятным сообщением, если подпись не
подтвердилась.

## Если что-то пошло не так

**Собранное приложение выходит или ничего не делает.** Ошибки, которые оконная
сборка обычно проглатывает, пишутся в `crash.log`; путь к файлу указан в диалоге
ошибки. Этот же файл записывает, что было нажато; он ротируется при 320 КБ,
сохраняя одну предыдущую копию в `crash.log.1`. Пришлите его вместе с описанием
проблемы.

- macOS: `~/Library/Application Support/PnP2PDF/crash.log`
- Windows: `%APPDATA%\PnP2PDF\crash.log`
- Linux: `$XDG_DATA_HOME/pnp2pdf/crash.log` (или `~/.local/share/pnp2pdf/crash.log`)

**«PnP2PDF is damaged and can't be opened» (macOS).** Скачанное неподписанное
приложение стоит под карантином — см. [Готовая сборка](#готовая-сборка).

**«No card images found».** Картинки должны заканчиваться на `.png`, `.jpg`,
`.jpeg`, `.tif` или `.tiff`; карты с рубашкой должны лежать в подпапке с именем
этой рубашки.

**Рубашки попали на лист как карты.** Не отмечена галочка **Double sided cards**
— см. [Раскладка папок](#раскладка-папок-с-картами).

**Приложение открывается как папка (macOS).** Устарел бандл или база запуска:
пересоберите `./build_app.sh`, затем выполните
`/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister -f dist/PnP2PDF.app`.

## Разработка

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты подменяют CustomTkinter, поэтому идут без экрана. Устройство пакета:

```
pnp2pdf/
├── app.py          цикл событий и запуск
├── cards.py        обход папки, сопоставление карт и рубашек
├── layout.py       раскладка по листам
├── render.py       отрисовка страницы: карты, линии реза, углы, зоны
├── pdf.py          запись CMYK PDF
├── preview.py      быстрый рендер низкого разрешения для предпросмотра
├── job.py          один запуск: карты → листы → PDF
├── cli.py          точка входа командной строки
└── ui/             окно, хелперы формы, рабочий поток
```

## Известные проблемы

- Архив для macOS собран под arm64, потому что его собирает тот же Python, который
  запускает скрипт сборки. На Intel Mac собери приложение сам: `./build_app.sh`.
- Обе сборки не подписаны, поэтому система спрашивает разрешение при первом
  запуске — см. [Готовая сборка](#готовая-сборка).
- Картинки растягиваются на область карты, поэтому изображение с другим соотношением
  сторон, чем выбранный размер карты, выглядит искажённым.
